# Project Notes

## Research Application

- This is a standalone `research` Django app intended to be integrated into the existing Django website.
- `index.html` is the template from the existing Django website.
- Only 4 pages are planned for the first release:
  - Doctor of Philosophy (PhD)
  - Master of Philosophy (MPhil)
  - Master of Research Methodology (MRM)
  - Doctor of Education (EdD)
- These pages will be pushed to GitHub so a backend developer can clone and integrate them.
- The existing Django website has a customized CMS that hides the code from users; logged-in users can manage the website through the CMS.
